A [`ViewTarget`](/api/hybrid-objects/view-target), the object that renders a scene into one view, offers two features: `target.pick(x, y)` finds the renderable under a point, and `target.takeSnapshot()` captures the next rendered frame. Both work from any thread and resolve after the next rendered frame; in `on-demand` render mode, a pending pick or snapshot renders that frame. If the target is disposed first, the Promise rejects with `FilamentDisposedError`.

Inside a [`<FilamentView>`](/api/components/filament-view), `useFilamentContext().target` is the view's target. It is `undefined` until the `ViewTarget` is created, and outside a `<FilamentView>`. Until the surface exists, `target.width` and `target.height` are 0. Imperatively, `engine.createViewTarget(view, options)` returns the target for a [`NativeFilamentView`](/api/components/native-filament-view).

## Picking

`target.pick(x, y)` takes a point in points (not pixels) from the top-left corner of the view, such as the `locationX` and `locationY` of a touch event. It resolves with a [`PickResult`](/api/types/pick-result), `{ entity, worldPosition }`, or `undefined` when nothing is under the point. `entity` is the renderable entity under the point, and `worldPosition` is where the point hits it in world space.

`<Model>` and `<ModelRenderer>` take an `onPress` callback that picks for you: when a touch on the closest `<FilamentView>` starts on one of the model's renderables, it is called with that entity and all of the model's entities. Imperatively, call `pick()` from your own touch handler and compare the entity with `model.entities`. A picked entity is a glTF node with a mesh; `model.getEntityName(entity)` returns its node name on the render thread.

<ApiTabs>
<Declarative>

```tsx
import { Alert } from 'react-native'
import { Camera, DefaultLight, FilamentView, Model, type Entity } from 'react-native-filament'

function PressableRocket() {
  const onPress = (entity: Entity, modelEntities: Entity[]) => {
    Alert.alert(`Entity ${entity}, one of ${modelEntities.length}`)
  }
  return (
    <FilamentView style={{ flex: 1 }}>
      <Camera />
      <DefaultLight />
      <Model source={require('./rocket.glb')} transformToUnitCube onPress={onPress} />
    </FilamentView>
  )
}
```

</Declarative>
<Imperative>

```tsx
import { Alert, Pressable, type GestureResponderEvent } from 'react-native'
import { NativeFilamentView, runOnRenderThread, type FilamentView } from 'react-native-filament'

function PickableView({ onView }: { onView: (view: FilamentView) => void }) {
  const onPress = async ({ nativeEvent }: GestureResponderEvent) => {
    const hit = await target.pick(nativeEvent.locationX, nativeEvent.locationY)
    if (hit == null || !model.entities.includes(hit.entity)) return
    const name = await runOnRenderThread(engine, () => {
      'worklet'
      return model.getEntityName(hit.entity)
    })
    Alert.alert(`Picked ${name}`)
  }
  return (
    <Pressable style={{ flex: 1 }} onPress={onPress}>
      <NativeFilamentView style={{ flex: 1 }} hybridRef={onView} />
    </Pressable>
  )
}
```

</Imperative>

## Snapshots

`target.takeSnapshot()` captures the next rendered frame and resolves with a [`Snapshot`](/api/hybrid-objects/snapshot), which keeps the pixels natively until you read them:

| Member | |
|---|---|
| `width`, `height` | Size in pixels. |
| `toArrayBuffer()` | Copies the pixels as RGBA bytes, top row first: `width * height * 4` bytes. |
| `saveToTemporaryFile()` | Encodes a PNG on a worker thread, writes it to a new file in the app's temporary directory and resolves with its `file://` URI. |

<ApiTabs>
<Declarative>

```tsx
import { Button } from 'react-native'
import { useFilamentContext } from 'react-native-filament'

function SaveFrameButton() {
  const { target } = useFilamentContext()
  const save = async () => {
    if (target == null) return
    const snapshot = await target.takeSnapshot()
    const uri = await snapshot.saveToTemporaryFile()
    console.log(`Saved ${snapshot.width}×${snapshot.height} to ${uri}`)
  }
  return <Button title="Save frame" disabled={target == null} onPress={save} />
}
```

</Declarative>
<Imperative>

```tsx
const snapshot = await target.takeSnapshot()

const pixels = new Uint8Array(snapshot.toArrayBuffer())
const offset = (Math.floor(snapshot.height / 2) * snapshot.width + Math.floor(snapshot.width / 2)) * 4
const [red, green, blue, alpha] = pixels.slice(offset, offset + 4)

const uri = await snapshot.saveToTemporaryFile()
```

</Imperative>
</ApiTabs>
