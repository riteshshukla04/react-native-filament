Load a model once with `instanceCount` to show it several times. Every instance shares the model's vertex data and textures, and has its own transform, animator and entities.

## Creating instances

[`<ModelInstance>`](/api/components/model-instance) configures one instance; `index` runs from `0` to `instanceCount - 1`, and an index out of range throws. Imperatively, `model.getInstance(index)` returns the [`ModelInstance`](/api/hybrid-objects/model-instance). `useModel` takes the same `instanceCount` option, and `<ModelRenderer>` accepts the same children as `<Model>`.

<ApiTabs>
<Declarative>

```tsx
import { Animator, Model, ModelInstance } from 'react-native-filament'

function Drones() {
  return (
    <Model source={require('./drone.glb')} instanceCount={2} transformToUnitCube>
      <ModelInstance index={0} translate={[-150, 0, 0]}>
        <Animator />
      </ModelInstance>
      <ModelInstance index={1} translate={[150, 0, 0]} />
    </Model>
  )
}
```

</Declarative>
<Imperative>

```tsx
import { runOnRenderThread } from 'react-native-filament'

const model = await engine.loadModel({ uri }, { instanceCount: 2 })

await runOnRenderThread(engine, () => {
  'worklet'
  scene.addModel(model)
  engine.transformManager.transformToUnitCube(model.rootEntity, model.boundingBox)
  engine.transformManager.setTranslation(model.getInstance(0).rootEntity, [-150, 0, 0])
  engine.transformManager.setTranslation(model.getInstance(1).rootEntity, [150, 0, 0])
})

const player = model.getInstance(0).animator.createPlayer()
player.play(0, {})
```

</Imperative>
</ApiTabs>

An instance's transform applies inside the model's transform, in the model's own units: the translations above are in the file's units, before the unit-cube fit, so useful values depend on the size of the model. Children of a `<ModelInstance>`, such as `<Animator>`, `<EntitySelector>` and `<DebugBox>`, apply to that instance only. An `<Animator>` or `<EntitySelector>` directly under the `<Model>` applies to its first instance. Keep the `player` reference: an `AnimationPlayer` stops when it is garbage collected.

## Adding instances later

`model.createInstance()` adds an instance on the render thread. Scenes that show the model show it too, and `model.instanceCount` and `model.entities` grow. Prefer `instanceCount` when you know the number up front: gltfio keeps every instance until the model is disposed. `<ModelInstance>` addresses only the instances that existed when the model loaded, so configure later ones through the returned object.

```tsx
import { runOnRenderThread } from 'react-native-filament'

const instance = await runOnRenderThread(engine, () => {
  'worklet'
  const offset = model.instanceCount
  const created = model.createInstance()
  engine.transformManager.setTranslation(created.rootEntity, [offset * 2, 0, 0])
  return created
})
```

## Sharing skeletons

Skinned instances can share one animated skeleton instead of each playing its own animation. Both methods run on the render thread.

- `instance.followSkeleton(source)` copies the local transform of every joint of `source` to the joint with the same name in `instance` at the start of each frame, after animation players run, and then updates the instance's bone matrices. `followSkeleton(undefined)` stops.
- `instance.attachSkin(skinIndex, entity)` skins `entity`, a mesh with bone indices and weights, with the instance's skeleton, for example to make clothing follow a character. `detachSkin(skinIndex, entity)` undoes it, and `instance.skinCount` gives the number of skins.

<ApiTabs>
<Declarative>

```tsx
import { useRenderThreadEffect, type Model } from 'react-native-filament'

function FollowLeader({ model }: { model: Model }) {
  useRenderThreadEffect(() => {
    'worklet'
    const follower = model.getInstance(1)
    follower.followSkeleton(model.getInstance(0))
    return () => follower.followSkeleton(undefined)
  }, [model])
  return null
}
```

</Declarative>
<Imperative>

```tsx
import { runOnRenderThread } from 'react-native-filament'

const leader = model.getInstance(0)
const follower = model.getInstance(1)

await runOnRenderThread(engine, () => {
  'worklet'
  follower.followSkeleton(leader)
})

const player = leader.animator.createPlayer()
player.play(1, {})
```

</Imperative>
</ApiTabs>

The "Skeleton sharing" example in `apps/shared/src/examples/SkeletonSharing.tsx` switches between both modes on two dancers.
