Each model instance has an [`Animator`](/api/hybrid-objects/animator) that lists the instance's glTF animations. To play one, create an [`AnimationPlayer`](/api/hybrid-objects/animation-player): it advances the animation natively on the render thread every frame, with no JavaScript per frame. Keep a reference to a player you create yourself: it stops when it is disposed or garbage collected, or when its model is disposed.

## Playing an animation

[`<Animator>`](/api/components/animator) plays an animation of the parent `<ModelInstance>`, or of the first instance of the parent `<Model>`. Unmount it to stop. Imperatively, `instance.animator.createPlayer()` returns a player, and `player.play(index, options)` starts an animation at the next frame.

<ApiTabs>
<Declarative>

```tsx
import { Animator, Model, type AnimationItem } from 'react-native-filament'

const logAnimations = (animations: AnimationItem[]) => console.log(animations)

function Dancer() {
  return (
    <Model source={require('./dancer.glb')}>
      <Animator animationIndex={0} loop speed={1} onAnimationsLoaded={logAnimations} />
    </Model>
  )
}
```

</Declarative>
<Imperative>

```tsx
const animator = model.getInstance(0).animator
console.log(animator.animations)

const player = animator.createPlayer()
player.play(0, { loop: true, speed: 1 })
```

</Imperative>
</ApiTabs>

| `<Animator>` prop | Default | |
|---|---|---|
| `animationIndex` | `0` | The animation to play. Each new value starts it from the beginning. Accepts a SharedValue. |
| `transitionDuration` | `0` | Seconds to blend from the previous animation. |
| `loop` | `true` | |
| `speed` | `1` | Playback rate; `1` is real time. |
| `time` | | Holds the animation at this time in seconds instead of playing it. Accepts a SharedValue. |
| `onAnimationsLoaded` | | Called with an [`AnimationItem`](/api/types/animation-item) `{ index, name, duration }` per animation when the Animator mounts, and again whenever the function changes, so pass a stable function such as a state setter. |

Changing `loop`, `speed` or `transitionDuration` also restarts the animation. `player.play()` takes [`PlayOptions`](/api/types/play-options): `loop` (default `true`), `speed` (default `1`) and `crossFadeSeconds` (default `0`). An index out of range throws.

## Switching with a cross-fade

A new animation index starts the new animation from the beginning, and `transitionDuration` blends the previous animation into it. Pass the index as a Reanimated `SharedValue<number>` to switch from the UI runtime without re-rendering.

```tsx
import { useState } from 'react'
import { Button } from 'react-native'
import { useSharedValue } from 'react-native-reanimated'
import { Animator, Model, type AnimationItem } from 'react-native-filament'

function Dancer() {
  const animationIndex = useSharedValue(0)
  const [animations, setAnimations] = useState<AnimationItem[]>([])
  return (
    <>
      <Model source={require('./dancer.glb')}>
        <Animator animationIndex={animationIndex} transitionDuration={0.4} onAnimationsLoaded={setAnimations} />
      </Model>
      {animations.map(({ index, name }) => (
        <Button key={index} title={name} onPress={() => (animationIndex.value = index)} />
      ))}
    </>
  )
}
```

Imperatively, call `player.play(1, { crossFadeSeconds: 0.4 })`.

## Scrubbing

To show a fixed pose, or to tie an animation to a slider or gesture, hold it at a time. The `time` prop pauses the player and seeks to the given second; imperatively, call `player.pause()` and `player.seek(seconds)`, which work from any thread, including a Reanimated worklet.

A paused player does not advance a cross-fade. While `time` is set, keep `transitionDuration` at `0`; otherwise a new `animationIndex` starts a cross-fade that stays on the previous animation. The same applies to `play(index, { crossFadeSeconds })` followed by `pause()`.

```tsx
import { useSharedValue } from 'react-native-reanimated'
import { Animator, Model } from 'react-native-filament'

function ScrubbedDancer() {
  const time = useSharedValue(0)
  return (
    <Model source={require('./dancer.glb')}>
      <Animator animationIndex={0} time={time} />
    </Model>
  )
}
```

## Controlling the player yourself

[`useAnimationPlayer(instance)`](/api/hooks/use-animation-player) creates a player for a [`ModelInstance`](/api/hybrid-objects/model-instance) and disposes it on unmount, so you can call `play`, `pause` and `seek` from event handlers or worklets.

```tsx
import { useMemo } from 'react'
import { Button } from 'react-native'
import { ModelRenderer, useAnimationPlayer, useModel } from 'react-native-filament'

function Dancer() {
  const model = useModel(require('./dancer.glb'))
  const instance = useMemo(() => (model.state === 'loaded' ? model.model.getInstance(0) : undefined), [model])
  const player = useAnimationPlayer(instance)

  return (
    <>
      <ModelRenderer model={model} />
      <Button title="Jump" onPress={() => player?.play(1, { loop: false, crossFadeSeconds: 0.3 })} />
      <Button title="Pause" onPress={() => player?.pause()} />
    </>
  )
}
```

## Applying animations frame by frame

For full control, apply animations yourself on the render thread with the instance's `Animator`. [`useAnimator(source)`](/api/hooks/use-animator) returns the animator of a loaded model's first instance, or of a `ModelInstance` you pass.

| Method | |
|---|---|
| `applyAnimation(index, seconds)` | Poses the instance at `seconds` into an animation. |
| `applyCrossFade(previousIndex, previousSeconds, alpha)` | Blends in a previous animation. Call it after `applyAnimation`; `alpha` of `1` shows only the current animation, `0` only the previous one. |
| `updateBoneMatrices()` | Updates the skin after posing. Call it last. |
| `resetBoneMatrices()` | Returns a skinned model to its bind pose. |

Frame listeners run before animation players, so do not also play an animation with a player on the same instance: the player overwrites your pose. `elapsedSeconds` counts from the Engine's first frame, not from when the model loaded.

<ApiTabs>
<Declarative>

```tsx
import { ModelRenderer, useAnimator, useFrameCallback, useModel } from 'react-native-filament'

function BlendedDancer() {
  const model = useModel(require('./dancer.glb'))
  const animator = useAnimator(model)

  useFrameCallback(({ elapsedSeconds }) => {
    'worklet'
    if (animator == null) return
    const [walk, run] = animator.animations
    animator.applyAnimation(1, elapsedSeconds % run!.durationSeconds)
    animator.applyCrossFade(0, elapsedSeconds % walk!.durationSeconds, Math.min(elapsedSeconds / 0.5, 1))
    animator.updateBoneMatrices()
  }, [animator])

  return <ModelRenderer model={model} />
}
```

</Declarative>
<Imperative>

```tsx
import { runOnRenderThread } from 'react-native-filament'

const animator = model.getInstance(0).animator

const subscription = await runOnRenderThread(engine, () => {
  'worklet'
  const [walk, run] = animator.animations
  return engine.addOnFrameListener(({ elapsedSeconds }) => {
    animator.applyAnimation(1, elapsedSeconds % run!.durationSeconds)
    animator.applyCrossFade(0, elapsedSeconds % walk!.durationSeconds, Math.min(elapsedSeconds / 0.5, 1))
    animator.updateBoneMatrices()
    return true
  })
})

subscription.remove()
```

</Imperative>
</ApiTabs>

## Morph targets

Morph targets (blend shapes) deform a mesh. Each renderable entity has its own list of targets and a weight per target.

- `<EntitySelector morphWeights={...}>` sets the weights of the selected entity in target order, starting at the first target. It accepts a `SharedValue<number[]>`.
- `renderableManager.setMorphWeights(entity, weights, offset)` sets weights starting at target `offset`, and `getMorphTargetCount(entity)` returns the number of targets. Writing past the last target throws.
- `model.getMorphTargetNames(entity)` returns the target names in index order. All three run on the render thread.

<ApiTabs>
<Declarative>

```tsx
import { useDerivedValue, useSharedValue } from 'react-native-reanimated'
import { EntitySelector, Model } from 'react-native-filament'

function Face() {
  const smile = useSharedValue(0)
  const weights = useDerivedValue(() => [smile.value, 1 - smile.value])
  return (
    <Model source={require('./avatar.glb')}>
      <EntitySelector byName="Head" morphWeights={weights} />
    </Model>
  )
}
```

</Declarative>
<Imperative>

```tsx
import { runOnRenderThread } from 'react-native-filament'

const head = model.getEntityByName('Head')!

await runOnRenderThread(engine, () => {
  'worklet'
  const { renderableManager } = engine
  const index = model.getMorphTargetNames(head).indexOf('mouthOpen')
  if (index >= 0) renderableManager.setMorphWeights(head, [1], index)
  console.log(renderableManager.getMorphTargetCount(head))
})
```

</Imperative>
</ApiTabs>
