react-native-filament 2.0 is a rewrite on [Nitro Modules](https://nitro.margelo.com). The React components keep their names and most of their props, so most apps migrate by updating dependencies, replacing the APIs below and following the type errors.

## Dependencies

- Follow [Getting Started](/docs#installation): React Native 0.88 or later, `react-native-nitro-modules` 1.0, `react-native-worklets` 0.13 with its `react-native-worklets/plugin` babel plugin, and the iOS Swift Package Manager setup.
- Remove `react-native-worklets-core` unless another library needs it.
- `react-native-gesture-handler` 2.30 or later is needed only for `useOrbitGestures`.

## Rendering is native

v1 ran a JS render callback every frame. In 2.0 the render loop is native: animations, camera manipulators and physics run on the Engine's render thread, and SharedValue-driven props update through worklets. It still renders every frame by default; `renderMode="on-demand"` renders only after something changed ([Rendering](/docs/rendering#render-modes)).

`renderCallback` still exists on `FilamentView` and now receives a worklet. While it is set, it keeps an `on-demand` Engine rendering every frame. `RenderCallbackContext.useRenderCallback(callback, deps)` becomes [`useFrameCallback(callback, deps)`](/docs/threading#per-frame-code).

| 1.x `FrameInfo` | 2.0 |
|---|---|
| `timestamp` | `timestampNs` |
| `passedSeconds` | `elapsedSeconds` |
| `timeSinceLastFrame` | `deltaSeconds` |
| `startTime` | removed |
| | `frameIndex`, new |

## Changed and removed APIs

| 1.x | 2.0 |
|---|---|
| `useWorkletEffect`, `useWorkletCallback`, `useWorkletMemo`, `workletContext` | Same names, now running on the render thread through react-native-worklets ([Threading](/docs/threading#the-1x-worklet-hooks)). `useWorkletCallback`'s type parameters are now `<Args, Result>`. A cleanup returned from `useWorkletEffect` runs on the render thread; in 1.x a cleanup that was not a worklet ran on the JS thread. |
| `useSyncSharedValue`, worklets-core `useDerivedValue` | Pass Reanimated SharedValues to the props and derive them with Reanimated's `useDerivedValue`. In render-thread code, read one through [`useValueBinding`](/docs/reanimated#reading-a-sharedvalue-on-the-render-thread). |
| `useBuffer`, `FilamentBuffer` | Loaders such as `engine.loadMaterial()` take a `{ uri }` or an `ArrayBuffer`. Components accept a `require()`d asset, a URI string, a `{ uri }` or an `ArrayBuffer`. |
| `withCleanupScope`, `release()`, `isValid` | `dispose()` on every native object. Disposing an owner disposes what it owns, and components and hooks dispose what they create ([Architecture](/docs/architecture#lifetime)). |
| `FilamentScene` view props such as `ambientOcclusionOptions`; `config`; `frameRateOptions` | View options moved to [`FilamentView`](/docs/rendering#view-options). `config` is removed. To cap the frame rate, use `targetFrameRate` on `FilamentView`. |
| `FilamentView` `enableTransparentRendering`, on by default | `transparent`, off by default. Android uses a `SurfaceView`, or a `TextureView` when `transparent` is set. |
| `useFilamentContext()` returning `renderer`, `nameComponentManager`, `choreographer` | Removed. `view` is `View \| undefined` and set only inside a `FilamentView`, which also provides `target`. |
| `useModel()` returning `asset`; `shouldReleaseSourceData`; `getAssetFromModel` | `useModel()` returns `{ state: 'loading' }` or `{ state: 'loaded', model, boundingBox, rootEntity }`. The other two are removed. |
| `setLogger` | Removed. |
| `Entity` as `{ id }`; `AABB` with `min` and `max` | `Entity` is a number. `Aabb` has `center` and `halfExtent` only. |
| String unions `'FXAA'`, `'LOW'`, `'focused_point'`, `'disable_deactivation'` | Kebab-case: `'fxaa'`, `'low'`, `'focused-spot'`, `'never-sleep'`. |
| `Mat4` as a host object; the `create*Options()` helpers | `Mat4` is a plain column-major array and options are plain objects. The helpers are removed. |
| Light `intensity` | The `Light` component keeps `intensity`. The imperative options are `intensityLux` and `intensityLumens`. |

Passing a SharedValue to a prop:

```tsx title="Before"
const animatedRotationY = useSharedValue(0)
const rotationY = useSyncSharedValue(animatedRotationY)
const rotation = useDerivedValue<Float3>(() => {
  'worklet'
  return [0, rotationY.value, 0]
})
```

```tsx title="After"
import { useDerivedValue, useSharedValue } from 'react-native-reanimated'
import { Model, type Float3 } from 'react-native-filament'

function Spinner() {
  const rotationY = useSharedValue(0)
  const rotation = useDerivedValue<Float3>(() => [0, rotationY.value, 0])
  return <Model source={require('./drone.glb')} rotate={rotation} />
}
```

Moving a view option:

```tsx title="Before"
<FilamentScene ambientOcclusionOptions={{ enabled: true }}>
  <FilamentView style={{ flex: 1 }} />
</FilamentScene>
```

```tsx title="After"
<FilamentScene>
  <FilamentView style={{ flex: 1 }} ambientOcclusionOptions={{ enabled: true }} />
</FilamentScene>
```

## Transforms

Transform props are absolute: the local transform is `translate · rotate · scale`, after the unit-cube fit when `transformToUnitCube` is set, and after the entity's own transform for `EntitySelector`. `multiplyWithCurrentTransform` (default `true` in 1.x) is removed; nest `ModelInstance` inside `Model` to compose transforms.

`TransformManager` takes values instead of host objects:

| 1.x | 2.0 |
|---|---|
| `setEntityPosition(entity, position, multiply)` | `setTranslation(entity, position)` |
| `setEntityRotation(entity, angle, axis, multiply)` | `setRotation(entity, quaternionFromAxisAngle(axis, angle))` |
| `setEntityScale(entity, scale, multiply)` | `setScale(entity, scale)` |
| `getTransform(entity).translation` | `getTransform(entity)[12..14]` (column-major `Mat4`) |
| `updateTransformByRigidBody(entity, body)` | create the body with `entity` |

With `multiply` set to `false`, the 1.x setters replaced the whole local transform; the 2.0 setters replace only their part and keep the rest. For `multiply` set to `true`, multiply the new matrix by `getTransform(entity)` and write it with `setTransform`.

## Animations, camera and recording

- `Animator` plays natively through an `AnimationPlayer`. It accepts a SharedValue `animationIndex` and adds `transitionDuration`, `loop`, `speed` and `time` ([Animations](/docs/animations)).
- `useCameraManipulator` takes `homePosition` (1.x: `orbitHomePosition`), `targetPosition`, `upVector`, and numbers for `orbitSpeed` and `zoomSpeed` (1.x: arrays). The default home position moved from `[0, 0, 8]` to `[0, 0, 4]`. `useOrbitGestures(manipulator)` returns the gesture, and `Camera` takes `cameraManipulator` ([Camera](/docs/camera#orbiting-with-gestures)).
- `useRecorder(options)` returns the `Recorder`, or `undefined` until it exists, instead of `{ recorder, swapChain }`; `bitRate` is optional. `recorder.record(frameCount)` resolves with the MP4's URI and replaces `startRecording`, `renderFrame` and `stopRecording`. `useRecorderRenderLoop(recorder, render, deps)` takes a dependency list, and `render` receives a `FrameInfo` and returns nothing ([Recording](/docs/recording)).

## Physics

Physics moved to the `react-native-filament-physics` package; install it and import the hooks from there ([Physics](/docs/physics)).

| 1.x | 2.0 |
|---|---|
| `useWorld(0, -9.8, 0)` | `useWorld({ gravity: [0, -9.8, 0] })` |
| `useBoxShape(x, y, z)` | `useBoxShape(world, [x, y, z])` |
| `useStaticPlaneShape(nx, ny, nz, c)` | `useStaticPlaneShape(world, [nx, ny, nz], c)` |
| `useRigidBody({ world, mass, origin, shape, id })` | `useRigidBody(world, { mass, position, shape, id, entity })` |
| `world.stepSimulation(...)` in a render callback | Automatic; set `autoStep: false` and call `world.step(deltaSeconds)` to step manually |
| `collisionCallback` | `world.addOnCollisionListener(events => keepListening)` |

## Threading

Methods that touch Filament run on the render thread and throw an error starting with `FilamentThreadError` when called from another thread. Each method's documentation names its thread ([Threading](/docs/threading)).
