react-native-filament contains native code, so it needs a [development build](https://docs.expo.dev/develop/development-builds/introduction/) or [prebuild](https://docs.expo.dev/workflow/prebuild/). It does not run in Expo Go. It has no config plugin, so there is nothing to add to `plugins` in `app.json`.

`apps/expo-example` is an Expo SDK 58 app (React Native 0.88.1) that runs the same examples as the React Native CLI app in `apps/example`. The requirements in [Getting Started](/docs#requirements) apply.

<Callout type="warn" title="iOS with Expo is not verified">
The library's iOS sources build through Swift Package Manager; its podspec contains no sources. Expo's CocoaPods-based prebuild has not been verified with it since that change.
</Callout>

## Installation

<Steps>
<Step>

### Install the packages

```sh
npx expo install react-native-filament react-native-nitro-modules@alpha-nightly react-native-worklets
```

`expo install` picks the `react-native-worklets` version that matches your SDK (0.13.0 for SDK 58, within the 0.13 range react-native-filament requires). Install `react-native-reanimated` and `react-native-gesture-handler` the same way if you use them.

</Step>
<Step>

### Babel

`babel-preset-expo` adds `react-native-worklets/plugin` automatically when `react-native-worklets` is installed, so a custom `babel.config.js` only needs `presets: ['babel-preset-expo']`.

</Step>
<Step>

### Configure Metro

```js title="metro.config.js"
const { getDefaultConfig } = require('expo/metro-config')
const { drawableFileTypes } = require('@react-native/asset-utils')

drawableFileTypes.delete('ktx')

const config = getDefaultConfig(__dirname)
config.resolver.assetExts = [...config.resolver.assetExts, 'glb', 'ktx', 'filamat']

module.exports = config
```

`drawableFileTypes.delete('ktx')` keeps `.ktx` assets out of Android's drawable folders in release builds; see [Getting Started](/docs#installation).

</Step>
<Step>

### Build and start

```sh
npx expo run:ios
npx expo run:android
npx expo start --dev-client
```

`npx expo prebuild` generates the native projects instead. The first Gradle build downloads the prebuilt Filament binaries and verifies their checksums.

</Step>
</Steps>

Rendering code is the same as in a React Native CLI app; see [Render your first model](/docs#render-your-first-model).

`apps/expo-example/plugins` holds three local config plugins for that app's own build (`withGradleMemory`, `withMinimumPodDeploymentTarget` and `withSceneLifecycle`). react-native-filament does not ship them.
