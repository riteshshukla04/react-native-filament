![Coins falling onto a floor](/img/demo-coins_physics.gif)

react-native-filament includes [Bullet](https://github.com/bulletphysics/bullet3) physics. A physics world belongs to an Engine and steps natively on its render thread with every rendered frame. A rigid body can move an entity, so a falling model needs no JS per frame.

Every member of `PhysicsWorld`, `CollisionShape` and `RigidBody` runs on the render thread, except a shape's `type` and a body's `id`, `mass` and `shape`. The hooks create these objects for you there; imperative code calls them inside [`runOnRenderThread`](/api/functions/run-on-render-thread).

## World, shapes and bodies

`useWorld(options)` creates a world for the closest `<FilamentScene>`, returns `undefined` until it exists, and disposes it with its bodies and shapes on unmount. Imperatively, call `engine.createPhysicsWorld(options)`. Keep and dispose the world yourself: it and its bodies keep each other alive, and `world.dispose()` disposes the bodies and shapes too.

`PhysicsWorldOptions` default to `gravity: [0, -9.81, 0]` (meters per second squared), `fixedTimeStepSeconds: 1 / 60`, `maxSubSteps: 4` (most fixed steps taken per frame; time beyond them is dropped) and `autoStep: true`, which steps the world once per rendered frame by the frame's `deltaSeconds`. Turn `autoStep` off to call `world.step(deltaSeconds)` yourself.

A shape describes the geometry used for collisions, and several bodies can share one. Each hook returns `undefined` until the world and the shape exist, recreates the shape when an argument changes and disposes it on unmount.

- `useBoxShape(world, halfExtent)`: a box with half sizes `[x, y, z]` (`world.createBoxShape`).
- `useSphereShape(world, radius)` (`world.createSphereShape`).
- `useCylinderShape(world, halfExtent, axis)`: a cylinder whose height runs along `'x'`, `'y'` or `'z'`; the hook's `axis` defaults to `'y'` (`world.createCylinderShape`).
- `useStaticPlaneShape(world, normal, constant)`: the infinite plane `dot(normalize(normal), point) = constant`, which only static bodies may use (`world.createStaticPlaneShape`).

On the render thread, a shape also has a `localScaling` and a collision `margin` in meters.

`useRigidBody(world, options)` creates a body once `world` and `options` exist, recreates it when an option changes and disposes it on unmount; pass `undefined` as `options` while the shape is still loading. Imperatively, call `world.createRigidBody(options)`.

`RigidBodyOptions` take a `shape` and a `mass` in kilograms (`0` makes a static body that never moves), and optionally `position` (default `[0, 0, 0]`), `rotation` (a unit quaternion, default `[0, 0, 0, 1]`), `id` (reported in collision events), `friction` (`0.5`), `restitution` (`0`), `linearDamping` and `angularDamping` (`0`), and an `entity` whose translation and rotation follow the body after every step while it keeps its own scale.

The coin drops from 3 meters onto a static floor. The coin's root entity is bound to its body, so the model moves with the simulation.

<Declarative>

```tsx
import {
  Camera, DefaultLight, FilamentScene, FilamentView, useCylinderShape, useModel, useRigidBody, useStaticPlaneShape, useWorld,
  type Model, type PhysicsWorld,
} from 'react-native-filament'

function Coin({ world, model }: { world: PhysicsWorld; model: Model }) {
  const shape = useCylinderShape(world, model.boundingBox.halfExtent, 'y')
  useRigidBody(world, shape == null ? undefined : { shape, mass: 1, position: [0, 3, 0], entity: model.rootEntity, id: 'coin' })
  return null
}

function FallingCoin() {
  const world = useWorld({ gravity: [0, -9.81, 0] })
  const coin = useModel(require('./coin.glb'))
  const floor = useStaticPlaneShape(world, [0, 1, 0], -1.5)
  useRigidBody(world, floor == null ? undefined : { shape: floor, mass: 0, id: 'floor' })

  return (
    <FilamentView style={{ flex: 1 }}>
      <Camera />
      <DefaultLight />
      {world != null && coin.state === 'loaded' && <Coin world={world} model={coin.model} />}
    </FilamentView>
  )
}

export function PhysicsScreen() {
  return (
    <FilamentScene>
      <FallingCoin />
    </FilamentScene>
  )
}
```

## Collisions

`world.addOnCollisionListener(listener)` calls `listener` on the render thread after each `step()` in which contacts began or ended; with `autoStep`, that is once per frame. Contacts are compared once per `step()`, after all its fixed sub-steps, so a touch that begins and ends within one `step()` is not reported. Each `CollisionEvent` has a `kind` (`'began'` on the first step two bodies touch, `'ended'` on the first step they no longer do) and the bodies `bodyA` and `bodyB`; use the body `id` to tell them apart. Return `true` to keep listening or `false` to remove the listener; `subscription.remove()` also removes it. To reach React state from the listener, schedule a call with `scheduleOnRN` from `react-native-worklets`.

```tsx
import { scheduleOnRN } from 'react-native-worklets'
import { useRenderThreadEffect, type PhysicsWorld } from 'react-native-filament'

function useOnLanded(world: PhysicsWorld | undefined, onLanded: () => void) {
  useRenderThreadEffect(() => {
    'worklet'
    if (world == null) return
    const subscription = world.addOnCollisionListener((events) => {
      const landed = events.some((event) => event.kind === 'began' && [event.bodyA.id, event.bodyB.id].includes('floor'))
      if (landed) scheduleOnRN(onLanded)
      return !landed
    })
    return () => subscription.remove()
  }, [world, onLanded])
}
```

Outside components, call `world.addOnCollisionListener()` inside `runOnRenderThread`.

## Changing bodies and stepping

On the render thread, a body exposes `linearVelocity`, `angularVelocity`, `activationState`, `friction`, `restitution` and its bound `entity` as properties, and `applyCentralImpulse()`, `applyCentralForce()`, `setDamping()`, `getTransform()` and `setTransform()` (which ignores scale) as methods. `activationState` is `'sleeping'` (rests until something touches it), `'never-sleep'` (stays awake) or `'simulation-disabled'` (frozen), among others. A world also has a writable `gravity` and a `bodyCount`.

In `on-demand` mode, an automatically stepped world keeps the Engine rendering while any body is awake. Creating a body requests a frame, but changing a body or `gravity` does not, so call [`engine.requestFrame()`](/docs/rendering#render-modes) afterwards.

With `autoStep: false`, the world moves only when you call `world.step(deltaSeconds)`, which advances the simulation in fixed steps, moves the bound entities and reports collisions.

<ApiTabs>
<Declarative>

```tsx
import { Button } from 'react-native'
import { composeTransform, useFilamentContext, useFrameCallback, useRenderThreadCallback, useWorld, type RigidBody } from 'react-native-filament'

function ResetButton({ body }: { body: RigidBody | undefined }) {
  const { engine } = useFilamentContext()
  const reset = useRenderThreadCallback(() => {
    'worklet'
    if (body == null) return
    body.setTransform(composeTransform([0, 3, 0], [0, 0, 0, 1]))
    body.linearVelocity = [0, 0, 0]
    body.angularVelocity = [0, 0, 0]
    body.applyCentralImpulse([0, 5, 0])
    engine.requestFrame()
  }, [body, engine])
  return <Button title="Throw again" onPress={() => reset()} />
}

function SlowMotion() {
  const world = useWorld({ autoStep: false })
  useFrameCallback((frame) => {
    'worklet'
    world?.step(frame.deltaSeconds * 0.25)
  }, [world])
  return null
}
```
