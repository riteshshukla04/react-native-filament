react-native-filament renders 3D scenes with Google's [Filament](https://google.github.io/filament) renderer. It is built on [Nitro Modules](https://nitro.margelo.com), and each Engine renders on its own native thread.

## Requirements

- React Native 0.88 or later.
- iOS 16 or later, and Android API 24 or later (the minimum of React Native 0.88).
- iOS renders with Metal. Android renders with Vulkan 1.1 where the device supports it and with OpenGL ES 3.0 otherwise ([Rendering](/docs/rendering#backends)).

## Installation

<Steps>
<Step>

### Install the packages

```npm
npm i react-native-filament react-native-nitro-modules@alpha-nightly react-native-worklets@0.13
```

[Nitro Modules](https://nitro.margelo.com) 1.0 and [react-native-worklets](https://docs.swmansion.com/react-native-worklets) 0.13 are required peers. [Reanimated](https://docs.swmansion.com/react-native-reanimated) and [Gesture Handler](https://docs.swmansion.com/react-native-gesture-handler) 2.30 or later are optional: Reanimated SharedValues drive the animatable props, and [`useOrbitGestures`](/api/hooks/use-orbit-gestures) returns a Gesture Handler gesture.

</Step>
<Step>

### Add the worklets babel plugin

```js title="babel.config.js"
module.exports = {
  presets: ['module:@react-native/babel-preset'],
  plugins: ['react-native-worklets/plugin'],
}
```

Use this plugin with or without Reanimated 4: `react-native-reanimated/plugin` only re-exports it.

</Step>
<Step>

### Set up iOS

The library builds iOS through Swift Package Manager (Nitro Modules 1.0), and its podspec contains no sources. Download Filament's iOS libraries once, then let React Native link the packages into your Xcode project:

```sh
node node_modules/react-native-filament/scripts/prepare-filament-apple.js
npx react-native spm
```

Every native library of the app needs a `Package.swift`. `npx react-native spm scaffold` generates one for a library that ships only a podspec.

</Step>
<Step>

### Configure Metro

```js title="metro.config.js"
const { getDefaultConfig, mergeConfig } = require('@react-native/metro-config')
const { drawableFileTypes } = require('@react-native/asset-utils')

drawableFileTypes.delete('ktx')

const defaultConfig = getDefaultConfig(__dirname)

module.exports = mergeConfig(defaultConfig, {
  resolver: {
    assetExts: [...defaultConfig.resolver.assetExts, 'glb', 'ktx', 'filamat'],
  },
})
```

`assetExts` lets you `require()` models, environments and materials. `@react-native/asset-utils` lists `ktx` as an Android drawable type, so without `drawableFileTypes.delete('ktx')` a release bundle puts `.ktx` files into `drawable-*` folders, which the Android build rejects. Add `@react-native/asset-utils` to your `devDependencies`.

</Step>
</Steps>

Using Expo? See [Expo](/docs/expo).

The Android build and `prepare-filament-apple.js` download the prebuilt Filament 1.78.0 binaries from GitHub and verify their SHA-256. To build without GitHub access, set `RNF_FILAMENT_BASE_URL` to a mirror of the release assets, or point `RNF_FILAMENT_IOS_ARCHIVE` (iOS) and `RNF_FILAMENT_ARCHIVE` (Android) at local copies.

## Render your first model

Models are glTF 2.0 binaries (`.glb`). A scene needs a view, a light (otherwise everything is black), a model and a camera.

<ApiTabs>
<Declarative>

```tsx title="MyScene.tsx"
import { Camera, DefaultLight, FilamentScene, FilamentView, Model } from 'react-native-filament'

export function MyScene() {
  return (
    <FilamentScene>
      <FilamentView style={{ flex: 1 }}>
        <Camera />
        <DefaultLight />
        <Model source={require('./drone.glb')} transformToUnitCube />
      </FilamentView>
    </FilamentScene>
  )
}
```

</Declarative>
<Imperative>

```tsx title="MyScene.tsx"
import { useEffect, useState } from 'react'
import { Image } from 'react-native'
import { defaultIndirectLightSource, Filament, NativeFilamentView, runOnRenderThread, type FilamentView } from 'react-native-filament'

const drone = Image.resolveAssetSource(require('./drone.glb'))!

export function MyScene() {
  const [view, setView] = useState<FilamentView>()

  useEffect(() => {
    if (view == null) return
    const starting = Filament.createEngine({}).then(async (engine) => {
      const [target, model, environment] = await Promise.all([
        engine.createViewTarget(view, {}),
        engine.loadModel({ uri: drone.uri }, {}),
        engine.loadIndirectLight(defaultIndirectLightSource, { intensity: 25_000 }),
      ])
      const { camera, sun } = await runOnRenderThread(engine, () => {
        'worklet'
        const scene = engine.createScene()
        const light = engine.createDirectionalLight({ castShadows: true })
        scene.setIndirectLight(environment)
        scene.addEntity(light.entity)
        scene.addModel(model)
        engine.transformManager.transformToUnitCube(model.rootEntity, model.boundingBox)
        const lens = engine.createCamera()
        lens.lookAt([0, 0, 8], [0, 0, 0], [0, 1, 0])
        target.setScene(scene)
        target.setCamera(lens)
        return { camera: lens, sun: light }
      })
      const resize = target.addOnResizeListener((width, height) => {
        runOnRenderThread(engine, () => {
          'worklet'
          camera.setLensProjection(28, width / height, 0.1, 100)
        })
      })
      return { engine, target, sun, resize }
    })
    return () => {
      starting.then(({ engine, resize }) => {
        resize.remove()
        engine.shutdown()
      })
    }
  }, [view])

  return <NativeFilamentView style={{ flex: 1 }} hybridRef={setView} />
}
```

</Imperative>
</ApiTabs>

The declarative components:

- [`<FilamentScene>`](/api/components/filament-scene) creates an Engine, a scene and a camera, and disposes them on unmount.
- [`<FilamentView>`](/api/components/filament-view) shows the scene. `Camera`, `Model` and the other components inside it draw nothing themselves; they configure the scene.
- [`<DefaultLight>`](/api/components/default-light) adds the bundled studio environment and a shadow-casting directional light.
- [`<Model>`](/api/components/model) loads a `.glb` and adds it to the scene. `transformToUnitCube` fits it into the cube from -1 to 1.
- [`<Camera>`](/api/components/camera) looks at the origin from `[0, 0, 8]`.

The imperative version uses the native objects. `engine.loadModel()` and `engine.loadIndirectLight()` work from any thread. Methods tagged `@thread render`, such as `createScene()` and `addModel()`, throw outside the render thread, so they run in [`runOnRenderThread()`](/api/functions/run-on-render-thread). The scene stores only a light's entity, and a `ViewTarget` stops rendering when it is garbage collected, so the example keeps `sun` and `target`. Imperative examples in the other guides use an `engine`, `scene`, `camera`, `target` and `model` created this way.

You can mix both styles: inside a `FilamentScene`, [`useFilamentContext()`](/api/hooks/use-filament-context) returns the Engine, scene, camera and managers the components use.
