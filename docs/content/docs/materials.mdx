![A rocket switching to a blue texture](/img/demo-change-textures.gif)

In Filament, a [`Material`](/api/hybrid-objects/material) is a compiled shader with named parameters, and a [`MaterialInstance`](/api/hybrid-objects/material-instance) holds one set of values for them. Every primitive of a renderable entity is drawn with one material instance. glTF models bring their own: each glTF material becomes a material instance named after it, and its PBR values and textures are parameters you can change.

To change a material you need the entity that uses it and, for textures, the material's name. Open the model in Blender to find both. In [this toy rocket](https://www.cgtrader.com/free-3d-models/space/spaceship/toy-rocket-4k) the outliner lists the entities (`Engine`, `Tip`, `Wings`, ...) and the material is `Toy Ship`:

![The rocket in Blender, with its entities and material](/img/blender-explanation-materials.png)

At runtime, `renderableManager.getMaterialInstanceAt(entity, primitiveIndex)` returns the material instance of one primitive, and `instance.instanceName` is the glTF material name.

## Changing parameters

`<EntitySelector materialParameters={...}>` sets glTF PBR parameters of the selected entity. Each [`MaterialParametersItem`](/api/types/material-parameters-item) changes the material instance of one primitive (`index`, default `0`); pass an array to change several. Every value accepts a SharedValue.

| Parameter | Type |
|---|---|
| `baseColorFactor` | `Float4`, linear RGBA |
| `emissiveFactor` | `Float3`, linear RGB |
| `roughnessFactor`, `metallicFactor`, `reflectance`, `clearCoatFactor`, `clearCoatRoughnessFactor` | `number` |

Removing a parameter from `materialParameters` does not restore its original value. In `on-demand` [render mode](/docs/rendering#render-modes), only SharedValue parameters request a frame; after any other parameter or texture change, call `engine.requestFrame()`.

<ApiTabs>
<Declarative>

```tsx
import { EntitySelector, Model } from 'react-native-filament'

function Rocket() {
  return (
    <Model source={require('./rocket.glb')}>
      <EntitySelector
        byName="Tip"
        materialParameters={{ index: 0, parameters: { baseColorFactor: [0.1, 0.3, 1, 1], roughnessFactor: 0.2 } }}
      />
    </Model>
  )
}
```

</Declarative>
<Imperative>

```tsx
import { runOnRenderThread } from 'react-native-filament'

const tip = model.getEntityByName('Tip')!

await runOnRenderThread(engine, () => {
  'worklet'
  const instance = engine.renderableManager.getMaterialInstanceAt(tip, 0)
  instance.setFloat4Parameter('baseColorFactor', [0.1, 0.3, 1, 1])
  instance.setFloatParameter('roughnessFactor', 0.2)
})
```

</Imperative>
</ApiTabs>

All `MaterialInstance` members run on the render thread: a setter per parameter type (`setFloatParameter`, `setIntParameter`, `setFloat3Parameter`, `setFloat4Parameter`, `setMat3Parameter`), the matching getters, `setColorParameter(name, color, 'srgb' | 'linear')`, `hasParameter(name)`, `setTexture(name, texture, sampler)`, `cullingMode`, `transparencyMode`, and `instanceName` (the glTF material name for a model). Setting a parameter the material does not declare, or with the wrong type, throws.

### Animating parameters

With a SharedValue, a parameter changes from the UI runtime without React renders. Imperatively, read a [`ValueBinding`](/api/hybrid-objects/value-binding) in a frame listener: `useValueBinding` or `engine.createValueBinding()` gives one that any thread can write and the render thread can read. The alpha only has an effect on a material that blends, such as the one in `coin_with_alpha.glb` in `apps/shared/assets`.

<ApiTabs>
<Declarative>

```tsx
import { Button } from 'react-native'
import { useDerivedValue, useSharedValue, withTiming } from 'react-native-reanimated'
import { EntitySelector, Model, type Float4 } from 'react-native-filament'

function FadingTip() {
  const opacity = useSharedValue(1)
  const baseColorFactor = useDerivedValue<Float4>(() => [1, 1, 1, opacity.value])
  return (
    <>
      <Model source={require('./rocket.glb')}>
        <EntitySelector byName="Tip" materialParameters={{ parameters: { baseColorFactor } }} />
      </Model>
      <Button title="Fade out" onPress={() => (opacity.value = withTiming(0, { duration: 1000 }))} />
    </>
  )
}
```

</Declarative>
<Imperative>

```tsx
import { runOnRenderThread } from 'react-native-filament'

const opacity = engine.createValueBinding(1)
const tip = model.getEntityByName('Tip')!

const subscription = await runOnRenderThread(engine, () => {
  'worklet'
  const instance = engine.renderableManager.getMaterialInstanceAt(tip, 0)
  let applied = -1
  return engine.addOnFrameListener(() => {
    if (opacity.value !== applied) {
      applied = opacity.value
      instance.setFloat4Parameter('baseColorFactor', [1, 1, 1, applied])
    }
    return false
  })
})

opacity.set(0.5)
```

</Imperative>
</ApiTabs>

## Replacing textures

`<EntitySelector textureMap={{ materialName, textureSource, srgb }}>` loads an image and sets it as the `baseColorMap` of each of the selected entity's material instances named `materialName` (the glTF material name). Imperatively, load the texture with `engine.loadTexture()` and bind it with `instance.setTexture()` on the render thread.

<ApiTabs>
<Declarative>

```tsx
import { EntitySelector, Model } from 'react-native-filament'

const blueBaseColor = require('./rocket_BaseColor_Blue.png')

function BlueRocket() {
  return (
    <Model source={require('./rocket.glb')}>
      <EntitySelector byName="Tip" textureMap={{ materialName: 'Toy Ship', textureSource: blueBaseColor }} />
      <EntitySelector byName="Wings" textureMap={{ materialName: 'Toy Ship', textureSource: blueBaseColor }} />
    </Model>
  )
}
```

</Declarative>
<Imperative>

```tsx
import { Image } from 'react-native'
import { runOnRenderThread } from 'react-native-filament'

const { uri } = Image.resolveAssetSource(require('./rocket_BaseColor_Blue.png'))!
const blue = await engine.loadTexture({ uri }, { srgb: true })

await runOnRenderThread(engine, () => {
  'worklet'
  const { renderableManager } = engine
  const entity = model.getEntityByName('Tip')
  if (entity == null) return
  for (let primitive = 0; primitive < renderableManager.getPrimitiveCount(entity); primitive++) {
    const instance = renderableManager.getMaterialInstanceAt(entity, primitive)
    if (instance.instanceName === 'Toy Ship') instance.setTexture('baseColorMap', blue, {})
  }
})
```

</Imperative>
</ApiTabs>

Unmounting the `<EntitySelector>` disposes the loaded texture and unbinds it; the original texture is not restored.

## Loading textures

`engine.loadTexture(source, options)` loads a PNG, JPEG or KTX2 image. Images are decoded on a worker thread, and the Promise resolves with a [`Texture`](/api/hybrid-objects/texture) (`width`, `height` in pixels) once every mip level is uploaded, without blocking rendering. `srgb` (default `true`) marks the image as sRGB-encoded; set it to `false` for data such as normal or roughness maps.

`setTexture(name, texture, sampler)` takes [`SamplerOptions`](/api/types/sampler-options): `minFilter` (default `'linear-mipmap-linear'`), `magFilter` (`'linear'`) and `wrapS` and `wrapT` (`'repeat'`).

A material instance keeps the textures bound to it alive. `texture.dispose()` unbinds the texture from every material instance, and `useDisposableResource` disposes it on unmount.

```tsx
import { Image } from 'react-native'
import { useDisposableResource, useFilamentContext, useRenderThreadEffect, type Entity } from 'react-native-filament'

const pixelArt = Image.resolveAssetSource(require('./pixel-art.png'))!

function PixelArtTexture({ entity }: { entity: Entity }) {
  const { engine, renderableManager } = useFilamentContext()
  const texture = useDisposableResource(() => engine.loadTexture({ uri: pixelArt.uri }, { srgb: true }), [engine])

  useRenderThreadEffect(() => {
    'worklet'
    if (texture == null) return
    const instance = renderableManager.getMaterialInstanceAt(entity, 0)
    instance.setTexture('baseColorMap', texture, { minFilter: 'nearest', magFilter: 'nearest', wrapS: 'clamp-to-edge' })
  }, [texture, entity, renderableManager])
  return null
}
```

## Custom materials

`engine.loadMaterial(source)` loads a compiled material (`.filamat`). Compile your `.mat` definitions with `matc` from the [Filament 1.78 release](https://github.com/google/filament/releases/tag/v1.78.0); a material compiled for another version rejects with a `FilamentAssetError` that names both versions. The [Filament materials guide](https://google.github.io/filament/Materials.html) describes the material language.

A `Material` has `materialName` and `parameterNames` (any thread), `defaultInstance` (the instance shared by every renderable that uses the material without its own) and `createInstance()` (render thread).

`renderableManager.setMaterialInstanceAt(entity, primitiveIndex, instance)` draws a primitive with an instance you created. The renderable keeps the instance alive until it is replaced. Disposing the instance falls back to its material's default instance, and disposing the material falls back to Filament's default material. A model's own material instances cannot be assigned to another primitive; create an instance from a `Material` instead.

```tsx
import { Image } from 'react-native'
import { useDisposableResource, useFilamentContext, useRenderThreadEffect, type Entity } from 'react-native-filament'

const toon = Image.resolveAssetSource(require('./toon.filamat'))!

function ToonShaded({ entity }: { entity: Entity }) {
  const { engine, renderableManager } = useFilamentContext()
  const material = useDisposableResource(() => engine.loadMaterial({ uri: toon.uri }), [engine])

  useRenderThreadEffect(() => {
    'worklet'
    if (material == null) return
    const instance = material.createInstance()
    instance.setColorParameter('baseColor', [1, 0.6, 0.2, 1], 'srgb')
    renderableManager.setMaterialInstanceAt(entity, 0, instance)
  }, [material, entity, renderableManager])
  return null
}
```

`toon.filamat` stands for your own material with a `float4 baseColor` parameter. Custom materials also draw the geometry the library creates: `engine.createPlane(options, materialInstance)` and `engine.createBackground(materialInstance)` ([Lights](/docs/lights#shadows), [Skybox and backgrounds](/docs/skybox#background-images)).

## Material variants

glTF files that use `KHR_materials_variants` hold alternative sets of materials. `instance.materialVariants` lists their names, and `instance.applyMaterialVariant(index)` switches an instance to one on the render thread.
