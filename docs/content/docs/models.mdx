react-native-filament renders glTF 2.0 binaries (`.glb`) that are self-contained. A model loads once, uploads its buffers and textures to the GPU, and can then be added to any scene of the same Engine. Convert other formats to `.glb` with Blender or an online converter. [Getting Started](/docs#render-your-first-model) shows a model on screen.

The imperative examples on this page assume an `engine` and a `scene`: from `useFilamentContext()` inside a `<FilamentScene>`, or created as in Getting Started. Methods tagged `@thread render`, such as `scene.addModel()`, run inside [`runOnRenderThread`](/api/functions/run-on-render-thread).

## Asset sources

Components and hooks accept an [`AssetLike`](/api/types/asset-like): a `require()`d asset, a URI string, a `{ uri }` object or an `ArrayBuffer`. The Engine's loaders (`loadModel`, `loadTexture`, `loadMaterial`, `loadSkybox`, `loadIndirectLight`) accept an [`AssetSource`](/api/types/asset-source): `{ uri }` or an `ArrayBuffer`. Resolve a `require()`d asset with `Image.resolveAssetSource`, which returns `undefined` for an asset the bundler does not know.

```tsx
import { Image } from 'react-native'

const { uri } = Image.resolveAssetSource(require('./drone.glb'))!
await engine.loadModel({ uri }, {})
await engine.loadModel({ uri: 'drone.glb' }, {})
await engine.loadModel({ uri: `file://${path}` }, {})
await engine.loadModel({ uri: 'https://example.com/drone.glb' }, {})
await engine.loadModel(arrayBuffer, {})
```

`<Model source>` takes the same forms, and `require('./drone.glb')` directly.

A `{ uri }` is read natively, so the file's bytes never pass through JavaScript. An `ArrayBuffer` is copied once when the load starts, so you can reuse it right away.

- **`require()`**: list the extension in Metro's `assetExts` ([Getting Started](/docs#installation)). Release builds pack the asset into the app. Debug builds download it from the Metro server, which can make large files slow to load.
- **Bundled with the native app**: a plain name such as `{ uri: 'drone.glb' }`. On Android, put the file in `android/app/src/main/assets/`. On iOS, add it to your Xcode target so it is copied into the app bundle.
- **`file://`**: a file on the device.
- **`http(s)://`**: downloaded natively into the app's cache directory. While the app runs, loading the same URL again reuses that file and concurrent loads share one download; after a restart it is downloaded again.

## Loading state

[`useModel`](/api/hooks/use-model) loads a model and returns a [`FilamentModel`](/api/types/filament-model): `{ state: 'loading' }` until it is uploaded, then `{ state: 'loaded', model, boundingBox, rootEntity }`. [`<ModelRenderer>`](/api/components/model-renderer) renders such a value and nothing while it loads. `<Model>` is `useModel` plus `<ModelRenderer>`. `engine.loadModel()` resolves with the [`Model`](/api/hybrid-objects/model) once every buffer and texture is uploaded.

<ApiTabs>
<Declarative>

```tsx
import { ModelRenderer, useModel } from 'react-native-filament'

function Drone() {
  const model = useModel(require('./drone.glb'), { instanceCount: 1 })
  if (model.state === 'loaded') console.log(model.model.entities.length, model.boundingBox.halfExtent)
  return <ModelRenderer model={model} transformToUnitCube />
}
```

</Declarative>
<Imperative>

```tsx
import { runOnRenderThread } from 'react-native-filament'

const model = await engine.loadModel({ uri }, { instanceCount: 1 })
console.log(model.entities.length, model.boundingBox.halfExtent)

await runOnRenderThread(engine, () => {
  'worklet'
  scene.addModel(model)
})
```

</Imperative>
</ApiTabs>

A failed load rejects: bytes that are not a glTF 2.0 binary, or a `.glb` that is not self-contained, reject with `FilamentAssetError`, and a missing bundled asset rejects with an error that names it. Components and hooks throw the failure to the closest error boundary.

## Adding and removing

`useModel` and `<Model>` add every instance to the scene of the closest `<FilamentScene>` and remove them on unmount. Pass `addToScene: false` to load a model without showing it. Imperatively, `scene.addModel(model)` adds every renderable and light entity of every instance and `scene.removeModel(model)` removes them; adding a model that is already in the scene changes nothing.

<ApiTabs>
<Declarative>

```tsx
import { ModelRenderer, useFilamentContext, useModel, useRenderThreadEffect } from 'react-native-filament'

function ToggleableDrone({ visible }: { visible: boolean }) {
  const { scene } = useFilamentContext()
  const model = useModel(require('./drone.glb'), { addToScene: false })
  const loaded = model.state === 'loaded' ? model.model : undefined

  useRenderThreadEffect(() => {
    'worklet'
    if (loaded == null || !visible) return
    scene.addModel(loaded)
    return () => scene.removeModel(loaded)
  }, [loaded, visible, scene])

  return <ModelRenderer model={model} transformToUnitCube />
}
```

</Declarative>
<Imperative>

```tsx
import { runOnRenderThread } from 'react-native-filament'

await runOnRenderThread(engine, () => {
  'worklet'
  scene.removeModel(model)
})
```

</Imperative>
</ApiTabs>

`useModel` and `<Model>` dispose the model when the component unmounts or `source` or `instanceCount` changes. An imperative model stays alive while you reference it or a scene shows it; `model.dispose()` destroys it right away and removes it from every scene ([Architecture](/docs/architecture#lifetime)).

## Entities and bounds

A model is a tree of glTF nodes, and each node is an [`Entity`](/api/types/entity): a number the managers use to look up its transform, renderable and light components.

| Member | Thread | |
|---|---|---|
| `rootEntity` | any | Root of the model. |
| `entities` | any | Every entity of every instance, including instances created later. |
| `boundingBox` | any | `{ center, halfExtent }` in the model's own space, from the glTF accessors. |
| `instanceCount` | any | Number of instances ([Instancing](/docs/instancing)). |
| `getEntityByName(name)` | any | First entity with this glTF node name, or `undefined`. |
| `getEntityName(entity)` | render | glTF node name of an entity, or `undefined`. |

[`<EntitySelector>`](/api/components/entity-selector) picks one node of the parent `<Model>` or `<ModelInstance>` by name (`byName`) or by index in the instance's `entities` (`byIndex`), and throws when none matches. Under a `<Model>` it selects from the first instance. It changes the node's [transform](/docs/transforms), [material parameters and texture](/docs/materials) or [morph weights](/docs/animations#morph-targets).

<ApiTabs>
<Declarative>

```tsx
import { EntitySelector, Model } from 'react-native-filament'

function Rocket() {
  return (
    <Model source={require('./rocket.glb')} transformToUnitCube>
      <EntitySelector byName="Tip" scale={[1.5, 1.5, 1.5]} />
      <EntitySelector byIndex={2} scale={[0.5, 0.5, 0.5]} />
    </Model>
  )
}
```

</Declarative>
<Imperative>

```tsx
import { runOnRenderThread } from 'react-native-filament'

const tip = model.getEntityByName('Tip')
const third = model.getInstance(0).entities[2]

await runOnRenderThread(engine, () => {
  'worklet'
  if (tip != null) engine.transformManager.setScale(tip, [1.5, 1.5, 1.5])
  if (third != null) engine.transformManager.setScale(third, [0.5, 0.5, 0.5])
})
```

</Imperative>
</ApiTabs>

<Callout type="info" title="Bounds without accessor ranges">
`boundingBox` comes from the min and max values of the glTF accessors. If an asset lacks correct values, its renderables also get wrong culling bounds. Call `recomputeBoundingBoxes()` on an instance (`model.getInstance(i)`) on the render thread to compute its renderable bounds from their vertices. It does not change `model.boundingBox` and ignores skinning and morphing.
</Callout>

`<Model>` and `<ModelRenderer>` also take an `onPress` callback ([Picking](/docs/picking)).
