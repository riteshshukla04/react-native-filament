A transform places an entity relative to its parent. Matrices are column-major [`Mat4`](/api/types/mat4) arrays with the translation in elements 12, 13 and 14, and rotations are unit quaternions `[x, y, z, w]`.

## Transform props

`<Model>`, `<ModelRenderer>`, `<ModelInstance>`, `<EntitySelector>` and `<DebugBox>` take the [transform props](/api/types/transformation-props):

| Prop | Default | |
|---|---|---|
| `translate` | `[0, 0, 0]` | Position in meters. |
| `rotate` | `[0, 0, 0]` | Radians around X, then Y, then Z. |
| `scale` | `[1, 1, 1]` | |
| `transformToUnitCube` | `false` | Fits the bounding box into the cube from -1 to 1 around the origin first. Not on `EntitySelector` and `DebugBox`. |

The local transform is `translate · rotate · scale`, applied after the unit-cube fit, and after the entity's own transform for an `EntitySelector`. The props are absolute: changing `scale` from `[2, 2, 2]` to `[3, 3, 3]` gives a scale of 3, and re-renders never accumulate them. Removing every transform prop gives the entity back its original transform.

Imperatively, write the same transform with the [`TransformManager`](/api/hybrid-objects/transform-manager) on the render thread. [`composeTransform`](/api/functions/compose-transform) builds the matrix, [`quaternionFromEuler`](/api/functions/quaternion-from-euler) converts the `rotate` angles, and [`unitCubeTransform`](/api/functions/unit-cube-transform) returns the matrix that `transformManager.transformToUnitCube(entity, boundingBox)` sets.

<ApiTabs>
<Declarative>

```tsx
import { Model } from 'react-native-filament'

function Drone() {
  return <Model source={require('./drone.glb')} translate={[0, -1, 0]} rotate={[0, Math.PI / 4, 0]} scale={[2, 2, 2]} transformToUnitCube />
}
```

</Declarative>
<Imperative>

```tsx
import { composeTransform, quaternionFromEuler, runOnRenderThread, unitCubeTransform } from 'react-native-filament'

await runOnRenderThread(engine, () => {
  'worklet'
  const rotation = quaternionFromEuler([0, Math.PI / 4, 0])
  const placement = composeTransform([0, -1, 0], rotation, [2, 2, 2])
  engine.transformManager.setTransform(model.rootEntity, placement)
})

const binding = await runOnRenderThread(engine, () => {
  'worklet'
  const created = engine.createTransformBinding(model.rootEntity)
  created.setBase(unitCubeTransform(model.boundingBox))
  created.setScale(2, 2, 2)
  return created
})
```

</Imperative>
</ApiTabs>

The imperative example shows two ways: `setTransform` writes the whole local transform, and a binding with the unit-cube fit as its base applies a scale on top of the fit.

Instances are children of their model, so a `<ModelInstance>` transform applies inside the model's transform, in the model's own units ([Instancing](/docs/instancing)). `transformManager.getWorldTransform(entity)` returns the transform in world space, including every parent.

## Transform bindings

A [`TransformBinding`](/api/hybrid-objects/transform-binding) owns the local transform of one entity while it is alive. Its setters work from any thread, including a Reanimated worklet, and store the latest value. The latest values are applied together at the start of the next frame as `translation · rotation · scale · base`.

| Method | |
|---|---|
| `setTranslation(x, y, z)` | |
| `setRotation(x, y, z, w)` | A unit quaternion. |
| `setScale(x, y, z)` | |
| `setBase(matrix)` | A transform applied first, such as `unitCubeTransform(model.boundingBox)`. Defaults to the identity. |

A new binding starts from the entity's current transform. [`useTransformBinding(entity)`](/api/hooks/use-transform-binding) creates one while the component is mounted and returns `undefined` until it exists. Imperatively, `engine.createTransformBinding(entity)` runs on the render thread; call `dispose()` when you are done, and keep a reference until then because a binding stops when it is garbage collected.

<ApiTabs>
<Declarative>

```tsx
import { useEffect } from 'react'
import { quaternionFromAxisAngle, unitCubeTransform, useFrameCallback, useModel, useTransformBinding, ModelRenderer } from 'react-native-filament'

function RotatingDrone() {
  const model = useModel(require('./drone.glb'))
  const binding = useTransformBinding(model.state === 'loaded' ? model.rootEntity : undefined)

  useEffect(() => {
    if (binding != null && model.state === 'loaded') binding.setBase(unitCubeTransform(model.boundingBox))
  }, [binding, model])

  useFrameCallback(({ elapsedSeconds }) => {
    'worklet'
    const [x, y, z, w] = quaternionFromAxisAngle([0, 1, 0], elapsedSeconds)
    binding?.setRotation(x, y, z, w)
  }, [binding])

  return <ModelRenderer model={model} />
}
```

</Declarative>
<Imperative>

```tsx
import { quaternionFromAxisAngle, runOnRenderThread, unitCubeTransform } from 'react-native-filament'

const { binding, subscription } = await runOnRenderThread(engine, () => {
  'worklet'
  const created = engine.createTransformBinding(model.rootEntity)
  created.setBase(unitCubeTransform(model.boundingBox))
  const listener = engine.addOnFrameListener(({ elapsedSeconds }) => {
    const [x, y, z, w] = quaternionFromAxisAngle([0, 1, 0], elapsedSeconds)
    created.setRotation(x, y, z, w)
    return true
  })
  return { binding: created, subscription: listener }
})

subscription.remove()
binding.dispose()
```

</Imperative>
</ApiTabs>

<Callout type="warn" title="One writer per entity">
Transform props, `useTransformBinding` and `engine.createTransformBinding` write the entity's whole local transform whenever one of their values changes. Writing the same entity through the `TransformManager` as well works only until the binding's next change replaces it.
</Callout>

## The TransformManager

On the render thread, the `TransformManager` reads and writes transforms directly. Every method throws `FilamentInvalidEntityError` for an entity without a transform component in this Engine.

| Method | |
|---|---|
| `getTransform(entity)`, `getWorldTransform(entity)` | Local transform relative to the parent, and the transform in world space. |
| `setTransform(entity, matrix)` | Replaces the local transform. |
| `setTranslation(entity, translation)`, `setRotation(entity, quaternion)`, `setScale(entity, scale)` | Replace one part and keep the other two. |
| `getParent(entity)`, `setParent(entity, parent)` | Reads or changes the parent; `undefined` makes the entity a root. |
| `transformToUnitCube(entity, boundingBox)` | Sets the local transform that fits `boundingBox` into the cube from -1 to 1. |
| `openLocalTransformTransaction()`, `commitLocalTransformTransaction()` | Defers world-transform updates while you change many entities in one frame. |

In components, get it from `useFilamentContext()` and call it from a render-thread hook; imperatively, use `engine.transformManager` inside `runOnRenderThread`. In `on-demand` [render mode](/docs/rendering#render-modes), call `engine.requestFrame()` after writing through the TransformManager. Bindings request a frame themselves.

```tsx
import { quaternionFromAxisAngle, useFilamentContext, useRenderThreadEffect, type Entity } from 'react-native-filament'

function Lift({ entity }: { entity: Entity }) {
  const { engine, transformManager } = useFilamentContext()
  useRenderThreadEffect(() => {
    'worklet'
    const original = transformManager.getTransform(entity)
    transformManager.setTranslation(entity, [original[12], original[13] + 1, original[14]])
    transformManager.setRotation(entity, quaternionFromAxisAngle([0, 1, 0], Math.PI / 2))
    engine.requestFrame()
    return () => transformManager.setTransform(entity, original)
  }, [engine, entity, transformManager])
  return null
}
```

## Animating with SharedValues

Every transform prop accepts a Reanimated `SharedValue<Float3>`. Reanimated updates it on its UI runtime, a listener there writes each value into a `TransformBinding`, and the render thread applies it at the next frame, with no JS thread work and no React render. [`bindSharedValue`](/api/functions/bind-shared-value) does the same for a binding you create ([Reanimated](/docs/reanimated)).

Updating transform props through React state also works, but each change re-renders the component.

## Math helpers

These functions are worklets, so they run in any runtime: React Native's, Reanimated's UI runtime and the render thread.

| Function | Returns |
|---|---|
| [`quaternionFromAxisAngle(axis, angleRadians)`](/api/functions/quaternion-from-axis-angle) | Rotation around `axis`, which does not need to be normalized. |
| [`quaternionFromEuler([x, y, z])`](/api/functions/quaternion-from-euler) | Rotation by `x`, then `y`, then `z` radians around the world axes, as the `rotate` prop applies it. |
| [`lookAtRotation(eye, target, up)`](/api/functions/look-at-rotation) | Rotation of a camera at `eye` looking at `target`: its -Z axis points from `eye` toward `target`. `up` must not be parallel to `eye − target`, or the rotation is invalid. |
| [`composeTransform(translation, rotation, scale?)`](/api/functions/compose-transform) | Matrix that scales, then rotates, then translates. |
| [`unitCubeTransform(boundingBox)`](/api/functions/unit-cube-transform) | The matrix that `transformToUnitCube` sets. |

To point an entity's +Z axis from `position` at `target`, swap the arguments: `lookAtRotation(target, position, [0, 1, 0])`.
