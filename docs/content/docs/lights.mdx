A scene without light renders black. The light types:

- `directional`: light that travels in one direction, like sunlight.
- `sun`: a directional light whose angular size shapes its highlight on glossy surfaces.
- `point`: light from one position in all directions.
- `spot`: light from one position inside a cone. The intensity stays the same when the cone changes.
- `focused-spot`: a physically correct spot light. Its power spreads over its cone, so a wider cone looks dimmer.
- Image-based lighting (IBL): light from an environment image, with `<EnvironmentalLight />`.

## The `<Light />` component

`<Light />` creates a light in the scene of the closest `<FilamentScene>` and disposes it on unmount. Imperatively, create the light with one of the `engine.create*Light()` methods on the render thread and add its entity to the scene. The scene stores only the entity, so keep the `Light` object until you dispose it: when it is garbage collected, the light is destroyed and disappears from the scene ([Architecture](/docs/architecture#keep-references-to-what-you-create)).

```tsx
import { Light } from 'react-native-filament'

function Sunlight() {
  return <Light type="directional" intensity={10_000} colorKelvin={6_500} direction={[0, -1, 0]} castShadows />
}
```

"Spot" below covers both `spot` and `focused-spot`.

| Prop | Light types | Default | Description |
|---|---|---|---|
| `type` | all | required | `'directional'`, `'sun'`, `'point'`, `'spot'` or `'focused-spot'`. |
| `intensity` | all | 10,000 lux (directional), 100,000 lux (sun), 1,000 lm (point, spot) | Lux for directional and sun lights, lumens for point and spot lights. Accepts a SharedValue. |
| `colorKelvin` | all | `6500` | Correlated color temperature in kelvin. Accepts a SharedValue. |
| `castShadows` | all | `true` for directional and sun, `false` for point and spot | Whether the light casts shadows. |
| `direction` | directional, sun, spot | `[0, -1, 0]` | Direction the light travels or points in. Accepts a SharedValue. |
| `position` | point, spot | `[0, 0, 0]` | Position in meters. Accepts a SharedValue. |
| `falloffRadius` | point, spot | `1` | Distance in meters at which the light stops having an effect. |
| `spotLightCone` | spot | `[π/8, π/4]` | `[inner, outer]` cone angles in radians. |
| `angularRadiusDegrees` | sun | `0.545` | Angular radius of the sun in degrees. |
| `haloSize`, `haloFalloff` | sun | `10`, `80` | Halo of the sun disk. The library's skyboxes do not draw the disk, so they have no visible effect. |

The props map to the options of the `engine.create*Light()` methods: `intensity` becomes `intensityLux` for `createDirectionalLight()` and `createSunLight()`, and `intensityLumens` for `createPointLight()`, `createSpotLight()` and `createFocusedSpotLight()`; `spotLightCone` becomes `innerConeRadians` and `outerConeRadians`. Changing `type`, `castShadows`, `falloffRadius`, `spotLightCone` or a sun prop recreates the light. `intensity`, `colorKelvin`, `direction` and `position` update the existing light, and accept Reanimated SharedValues without React renders ([Reanimated](/docs/reanimated)).

```tsx
import { Light } from 'react-native-filament'

function Stage() {
  return (
    <>
      <Light type="sun" intensity={100_000} colorKelvin={5_500} direction={[0.4, -1, -0.5]} angularRadiusDegrees={0.8} />
      <Light type="point" intensity={10_000} colorKelvin={2_700} position={[1, 1, 0]} falloffRadius={4} />
      <Light
        type="focused-spot"
        intensity={10_000}
        position={[0, 3, 0]}
        direction={[0, -1, 0]}
        falloffRadius={6}
        spotLightCone={[Math.PI / 8, Math.PI / 6]}
      />
    </>
  )
}
```

<Callout type="info" title="Only one directional light counts">
By default Filament evaluates only the dominant directional or sun light of a scene (the one with the highest intensity); any other adds neither light nor shadows. `<DefaultLight />` already contains a directional light, so do not add a second one next to it. See `LightManager.h` in Filament.
</Callout>

<Callout type="info" title="Keep falloffRadius small">
`falloffRadius` defines a sphere of influence around a point or spot light. Larger radii can reduce performance significantly, especially with many lights, so avoid many overlapping spheres (see `LightManager.h` in Filament).
</Callout>

## The `<DefaultLight />` component

`<DefaultLight />` is a good starting point. It combines the bundled studio environment as [image-based lighting](#image-based-lighting-ibl) (25,000 lux) with a shadow-casting directional light (10,000 lux, 6,500 K). Imperatively, that is `engine.loadIndirectLight(defaultIndirectLightSource, { intensity: 25_000 })` with `scene.setIndirectLight()`, plus `engine.createDirectionalLight({ intensityLux: 10_000, colorKelvin: 6_500, castShadows: true })`; Getting Started shows it.

The bundled environment, `RNF_default_env_ibl.ktx`, is about 2 MB. If you never use `<DefaultLight />` or `defaultIndirectLightSource`, leave it out on Android by adding `RNF_excludeAssets=true` to `android/gradle.properties`. On iOS, Swift Package Manager always copies it into the library's resource bundle.

## Intensity and color

Directional and sun lights use illuminance in lux; point and spot lights use luminous power in lumens. `lightManager.setIntensity()` takes the same units, but `getIntensity()` returns candela for point and spot lights. Colors are a correlated color temperature in kelvin through `colorKelvin`. `engine.lightManager.setColor()` takes linear RGB instead, and `kelvinToLinearRgb(kelvin)` converts a temperature in any runtime, including render-thread worklets.

```tsx
import { kelvinToLinearRgb, runOnRenderThread, type Engine, type Entity } from 'react-native-filament'

function setCandleColor(engine: Engine, light: Entity) {
  return runOnRenderThread(engine, () => {
    'worklet'
    engine.lightManager.setColor(light, kelvinToLinearRgb(1_900))
  })
}
```

`engine.lightManager` reads and writes the light component of any entity on the render thread, including lights loaded with a glTF model, with getters and setters for intensity, color, position, direction, falloff, the spot cone and shadow casting. It throws `FilamentInvalidEntityError` for an entity without a light component. `useLightEntity(config)` takes the same configuration as `<Light />` and returns the `Light` object without adding it to a scene; pair it with `useEntityInScene(scene, light?.entity)`, as `<Light />` does.

## Image-based lighting (IBL)

Image-based lighting lights the scene with an environment cubemap. `<EnvironmentalLight source intensity />` loads a KTX1 cubemap with spherical harmonics, as Filament's `cmgen` tool writes it, and lights the scene with it while mounted. `intensity` is a brightness scale in lux and defaults to 25,000. `useIndirectLight(source, intensity)` does the same and returns the `IndirectLight`; with `intensity` undefined it uses 30,000. Imperatively, `engine.loadIndirectLight(source, { intensity })` (also 30,000 by default) and `scene.setIndirectLight()` do the same. A scene has at most one indirect light. The default environment is exported as `defaultIndirectLightSource`.

<ApiTabs>
<Declarative>

```tsx
import { EnvironmentalLight } from 'react-native-filament'

function Studio() {
  return <EnvironmentalLight source={require('./studio_ibl.ktx')} intensity={25_000} />
}
```

</Declarative>
<Imperative>

```tsx
import { Image } from 'react-native'
import { runOnRenderThread } from 'react-native-filament'

const { uri } = Image.resolveAssetSource(require('./studio_ibl.ktx'))!
const environment = await engine.loadIndirectLight({ uri }, { intensity: 25_000 })

await runOnRenderThread(engine, () => {
  'worklet'
  scene.setIndirectLight(environment)
})
```

</Imperative>
</ApiTabs>

`source={defaultIndirectLightSource}` uses the bundled environment at another intensity. `cmgen` writes a `*_ibl.ktx` file for lighting and a matching `*_skybox.ktx` for a [skybox](/docs/skybox). Add `ktx` to Metro's `assetExts` to `require()` them ([Getting Started](/docs#installation)).

## Shadows

Three settings decide whether a shadow appears:

1. The light casts shadows. Directional and sun lights do by default, point and spot lights do not.
2. The models cast and receive shadows. `<Model castShadow receiveShadow>` sets this for every renderable of a model and otherwise keeps the model's own settings. `useConfigureAssetShadow({ entities, castShadow, receiveShadow })` does the same for any list of entities.
3. The view renders shadows. `shadowing` is `true` by default, and `shadowType` picks the filtering: `'pcf'` (default), `'vsm'`, `'dpcf'` or `'pcss'`. On the iOS Simulator the default is `'vsm'`, because its Metal reports every PCF depth comparison as shadowed.

To show a shadow on the ground without drawing the ground itself, add a plane with a shadow-only material. `engine.createPlane({ width, depth }, materialInstance)` creates a horizontal plane centered at the origin that receives shadows by default. The examples' `transparent_shadow_material.filamat` (source `transparent_shadow_material.mat` in `apps/shared/assets`) has a `strength` float parameter for the shadow opacity.

```tsx
import { Image } from 'react-native'
import {
  Camera, DefaultLight, FilamentScene, FilamentView, Model, useDisposableResource, useEntityInScene, useFilamentContext, useRenderThreadCallback,
} from 'react-native-filament'

const shadowMaterial = Image.resolveAssetSource(require('./transparent_shadow_material.filamat'))!

function ShadowPlane() {
  const { engine, scene } = useFilamentContext()
  const material = useDisposableResource(() => engine.loadMaterial({ uri: shadowMaterial.uri }), [engine])
  const createPlane = useRenderThreadCallback(() => {
    'worklet'
    const instance = material!.createInstance()
    instance.setFloatParameter('strength', 0.2)
    return engine.createPlane({ width: 10, depth: 10 }, instance)
  }, [engine, material])
  const plane = useDisposableResource(() => (material == null ? undefined : createPlane()), [material, createPlane])
  useEntityInScene(scene, plane?.entity)
  return null
}

export function Shadows() {
  return (
    <FilamentScene>
      <FilamentView style={{ flex: 1 }} shadowType="vsm">
        <Camera cameraPosition={[0, 3, 8]} />
        <DefaultLight />
        <ShadowPlane />
        <Model source={require('./coin.glb')} translate={[0, 2, 0]} castShadow receiveShadow />
      </FilamentView>
    </FilamentScene>
  )
}
```
