A `Recorder` renders a scene offscreen into an H.264 MP4 file, as fast as the device's encoder accepts frames. It does not need a `<FilamentView>` on screen. On iOS the encoder is `AVAssetWriter`; on Android it is `MediaCodec` with `MediaMuxer`.

Frames advance on a fixed clock: frame `i` shows the scene at `i / fps` seconds, and every frame's `deltaSeconds` is `1 / fps` (0 for the first frame). Before each frame, the Engine applies its bindings and runs its frame listeners, animation players and physics on that clock.

## Recording a scene

`useRecorder(options)` creates a recorder for the scene and camera of the closest `<FilamentScene>`, returns `undefined` until it exists, and disposes it on unmount. Imperatively, `engine.createRecorder(options)` runs on the render thread and needs a scene and a camera. `recorder.record(frameCount)` renders `frameCount` frames and resolves with the `file://` URI of the finished MP4 in the app's temporary directory. Play it with a video player such as [react-native-video](https://github.com/TheWidlarzGroup/react-native-video), or save it with a media library module.

<Declarative>

```tsx
import { useState } from 'react'
import { Button, Text } from 'react-native'
import { Animator, Camera, DefaultLight, FilamentScene, Model, useRecorder } from 'react-native-filament'

const WIDTH = 720
const HEIGHT = 1280
const FPS = 60

function Recording() {
  const recorder = useRecorder({ width: WIDTH, height: HEIGHT, fps: FPS })
  const [uri, setUri] = useState<string>()
  const record = async () => setUri(await recorder?.record(FPS * 5))

  return (
    <>
      <Camera aspect={WIDTH / HEIGHT} />
      <DefaultLight />
      <Model source={require('./drone.glb')} transformToUnitCube>
        <Animator />
      </Model>
      <Button title="Record 5 s" disabled={recorder == null} onPress={record} />
      {uri != null && <Text>{uri}</Text>}
    </>
  )
}

export function RecordingScreen() {
  return (
    <FilamentScene>
      <Recording />
    </FilamentScene>
  )
}
```

<Imperative>

```tsx
import { Image } from 'react-native'
import { defaultIndirectLightSource, Filament, runOnRenderThread } from 'react-native-filament'

const drone = Image.resolveAssetSource(require('./drone.glb'))!
const FPS = 60

export async function recordDrone(): Promise<string> {
  const engine = await Filament.createEngine({})
  try {
    const [model, environment] = await Promise.all([
      engine.loadModel({ uri: drone.uri }, {}),
      engine.loadIndirectLight(defaultIndirectLightSource, {}),
    ])
    const recorder = await runOnRenderThread(engine, () => {
      'worklet'
      const created = engine.createRecorder({ width: 720, height: 1280, fps: FPS })
      const scene = engine.createScene()
      scene.setIndirectLight(environment)
      scene.addModel(model)
      engine.transformManager.transformToUnitCube(model.rootEntity, model.boundingBox)
      const camera = engine.createCamera()
      camera.lookAt([0, 0, 4], [0, 0, 0], [0, 1, 0])
      camera.setLensProjection(28, created.width / created.height, 0.1, 100)
      created.setScene(scene)
      created.setCamera(camera)
      return created
    })
    const player = model.getInstance(0).animator.createPlayer()
    player.play(0, {})
    const uri = await recorder.record(FPS * 5)
    player.dispose()
    return uri
  } finally {
    await engine.shutdown()
  }
}
```

</ApiTabs>

| `RecorderOptions` | Default | Description |
|---|---|---|
| `width`, `height` | required | Video size in pixels. Odd values are rounded down to even. |
| `fps` | required | Frame rate of the video. |
| `bitRate` | 0.1 bits per pixel per frame | Target H.264 bit rate in bits per second. |
| `clearOptions` | | How each frame is cleared before rendering, for example `{ color: [0, 0, 0, 1] }` in linear RGBA. |

`recorder.width`, `recorder.height` and `recorder.fps` report the values in use, and `recorder.view` holds the recorder's view options ([Rendering](/docs/rendering#view-options)).

## Things to know

- **Views pause while recording.** The Engine renders only the recorder's frames, and its `<FilamentView>`s stop updating. Record with an Engine that is not showing anything important, for example the one of a dedicated `<FilamentScene>`.
- **One recording at a time.** `record()` rejects with `FilamentBusyError` while the same recorder is still recording, and with `FilamentDisposedError` when the recorder or its Engine is disposed before it finishes.
- **Set the camera's aspect ratio.** A recorder has no view to take it from: pass `aspect` to `<Camera />`, or call `camera.setLensProjection()` with `recorder.width / recorder.height`.
- **Background.** Without a skybox, frames clear to `clearOptions.color`. Add a [skybox](/docs/skybox) or call `recorder.setClearOptions()`.
- **Per-frame changes.** Animation players and physics advance on the recorder's clock. Bindings apply the latest value written, so a Reanimated animation, which runs on the UI thread's real-time clock, shows whatever value it has when each frame renders. Drive other changes from [`useRecorderRenderLoop(recorder, render, deps)`](/api/hooks/use-recorder-render-loop), which runs the worklet `render` before every frame, including each recorded frame, where `frame.elapsedSeconds` advances by exactly `1 / fps`. Imperatively, use `engine.addOnFrameListener()`.

```tsx
import { quaternionFromAxisAngle, useFilamentContext, useModel, useRecorderRenderLoop, type Recorder } from 'react-native-filament'

function SpinningDrone({ recorder }: { recorder: Recorder | undefined }) {
  const { transformManager } = useFilamentContext()
  const drone = useModel(require('./drone.glb'))
  const root = drone.state === 'loaded' ? drone.rootEntity : undefined

  useRecorderRenderLoop(
    recorder,
    (frame) => {
      'worklet'
      if (root == null) return
      transformManager.setRotation(root, quaternionFromAxisAngle([0, 1, 0], frame.elapsedSeconds))
    },
    [root, transformManager]
  )
  return null
}
```
