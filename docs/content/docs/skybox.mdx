![A drone in front of a background image](/img/demo-backgroundimage.jpg)

A skybox is the background of a scene: every pixel no object covers shows it. It is one color or a cubemap, and it does not light the scene; for light from an environment, use [image-based lighting](/docs/lights#image-based-lighting-ibl). A scene has one skybox at a time.

<Callout type="info" title="Without a skybox">
A `<FilamentView>` is opaque by default and clears to black. Set `transparent` to show the React Native views behind it, or pass `clearOptions={{ color: [r, g, b, a] }}` (linear RGBA) for another clear color. Imperatively, pass `{ clearOptions }` to `engine.createViewTarget()` or call `target.setClearOptions()` on the render thread.
</Callout>

## A static color

`<Skybox />` takes `colorInHex`, an sRGB `#rrggbb` or `#rrggbbaa` string, or `color`, a linear RGBA array. Imperatively, `engine.createSkybox(color)` takes linear RGBA on the render thread and `scene.setSkybox()` shows it.

```tsx
import { Camera, DefaultLight, FilamentScene, FilamentView, Model, Skybox } from 'react-native-filament'

export function SkyBlue() {
  return (
    <FilamentScene>
      <FilamentView style={{ flex: 1 }}>
        <Camera />
        <DefaultLight />
        <Skybox colorInHex="#88defb" />
        <Model source={require('./drone.glb')} transformToUnitCube />
      </FilamentView>
    </FilamentScene>
  )
}
```

## A cubemap

With `source`, `<Skybox />` loads a KTX1 cubemap as Filament's `cmgen` tool writes it. Imperatively, `engine.loadSkybox(source)` reads the file natively and resolves with a `Skybox`; call it from any thread. `cmgen` also writes a `*_ibl.ktx` file for [image-based lighting](/docs/lights#image-based-lighting-ibl) of the same environment. To `require()` `.ktx` files, add `ktx` to Metro's `assetExts` ([Getting Started](/docs#installation)). Sources can also be a `file://` path, an `http(s)://` URL or an `ArrayBuffer`.

```tsx
import { Camera, FilamentScene, FilamentView, Light, Model, Skybox } from 'react-native-filament'

export function SkyboxScene() {
  return (
    <FilamentScene>
      <FilamentView style={{ flex: 1 }}>
        <Camera />
        <Light type="directional" intensity={100_000} colorKelvin={6_500} />
        <Model source={require('./drone.glb')} transformToUnitCube />
        <Skybox source={require('./environment_skybox.ktx')} />
      </FilamentView>
    </FilamentScene>
  )
}
```

## The `useSkybox` hook

`useSkybox(options)` takes the same options as `<Skybox />` and returns the `Skybox` once it exists. Pass `undefined` for no skybox, which makes it easy to switch the background on and off. When a `<Skybox />` unmounts or its options change, it removes its skybox from the scene and disposes it. Imperatively, `scene.setSkybox(undefined)` removes the background, and `skybox.dispose()` removes it from every scene that shows it.

```tsx
import { useSkybox } from 'react-native-filament'

function Background({ night }: { night: boolean }) {
  useSkybox(night ? { colorInHex: '#0b1026' } : undefined)
  return null
}
```

## Background images

[`<BackgroundImage>`](/api/components/background-image) draws a PNG, JPEG or KTX2 image behind the scene of the closest `<FilamentScene>` and fits it to the closest `<FilamentView>`. Cameras and lights do not affect it. Use one per scene. Imperatively, `engine.createBackground(materialInstance)` returns a [`Renderable`](/api/hybrid-objects/renderable), a full-screen triangle drawn behind everything else, and [`imageFitTransform`](/api/functions/image-fit-transform) computes the image's UV transform whenever the view's size changes.

<ApiTabs>
<Declarative>

```tsx
import { BackgroundImage, Camera, DefaultLight, FilamentScene, FilamentView, Model } from 'react-native-filament'

export function DroneOnPhoto() {
  return (
    <FilamentScene>
      <FilamentView style={{ flex: 1 }}>
        <Camera />
        <DefaultLight />
        <Model source={require('./drone.glb')} transformToUnitCube />
        <BackgroundImage
          source={require('./background.jpg')}
          materialSource={require('./background_image.filamat')}
          resizeMode="cover"
        />
      </FilamentView>
    </FilamentScene>
  )
}
```

</Declarative>
<Imperative>

```tsx
import { Image } from 'react-native'
import { imageFitTransform, runOnRenderThread } from 'react-native-filament'

const photo = Image.resolveAssetSource(require('./background.jpg'))!
const backgroundMaterial = Image.resolveAssetSource(require('./background_image.filamat'))!

const [image, material] = await Promise.all([
  engine.loadTexture({ uri: photo.uri }, {}),
  engine.loadMaterial({ uri: backgroundMaterial.uri }),
])

const { instance, background } = await runOnRenderThread(engine, () => {
  'worklet'
  const created = material.createInstance()
  created.setTexture('image', image, {})
  created.setIntParameter('showImage', 1)
  created.setFloat3Parameter('backgroundColor', [0, 0, 0])
  const renderable = engine.createBackground(created)
  scene.addEntity(renderable.entity)
  return { instance: created, background: renderable }
})

const resize = target.addOnResizeListener((width, height) => {
  runOnRenderThread(engine, () => {
    'worklet'
    instance.setMat3Parameter('transform', imageFitTransform(image.width, image.height, width, height, 'cover'))
  })
})
```

</Imperative>
</ApiTabs>

`materialSource` is a compiled Filament material (`.filamat`) with a `vertexDomain` of `device` and these parameters, which `<BackgroundImage>` sets for you:

| Parameter | Type | |
|---|---|---|
| `image` | `sampler2d` | The image. |
| `transform` | `mat3` | UV transform from `imageFitTransform`. |
| `backgroundColor` | `float3` | Color around the image when it does not fill the view. |
| `showImage` | `int` | `1` to draw the image, `0` for only the color. |

Use `background_image.filamat` from `apps/shared/assets`, next to its definition `background_image.mat`. A `.filamat` only loads if it was compiled for the material version of the bundled Filament, so compile edits with `matc` from Filament 1.78. `resizeMode` (default `'contain'`) is `'contain'` to show the whole image and fill the rest with `backgroundColor`, `'cover'` to fill the view and crop the image, or `'scale'` to stretch it. `background.dispose()` removes the background from every scene.
